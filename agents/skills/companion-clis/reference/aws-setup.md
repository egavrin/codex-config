# AWS CLI — one-time setup

If `aws --version` fails, install the AWS CLI once. See [`aws.md`](aws.md) for credentials, region rules, and commands.

```bash
# macOS
brew install awscli

# Linux
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o awscliv2.zip
unzip awscliv2.zip && sudo ./aws/install
```
